  # 💰 Finanzas API

  **Finanzas** es una API robusta diseñada para la gestión de finanzas personales y empresariales. Este proyecto ha
  sido desarrollado con el objetivo de implementar una arquitectura escalable, limpia y tipada, siguiendo las mejores
  prácticas de desarrollo de software moderno.

  ## 🚀 Características principales
  - **Servidor de alto rendimiento:** Construido con Node.js y Express.
  - **Tipado Estricto:** Implementación total de TypeScript para reducir errores en tiempo de ejecución y mejorar la
  mantenibilidad.
  - **Arquitectura Escalable:** Estructura preparada para la implementación de patrones de diseño como *Repository* y
  *Service Layer*.
  - **Endpoints Optimizados:** Rutas diseñadas para una respuesta rápida y eficiente.

  ## 🛠️ Stack Tecnológico
  - **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
  - **Entorno de ejecución:** [Node.js](https://nodejs.org/)
  - **Framework Web:** [Express.js](https://expressjs.com/)
  - **Control de Versiones:** Git & GitHub

  ## ⚙️ Instalación y Ejecución

  Para ejecutar este proyecto localmente, sigue estos pasos:

  1. **Clonar el repositorio:**
     ```bash
     git clone https://github.com/Santiagoiu/finanzas-api.git
     cd finanzas-api

  2. Instalar las dependencias:
  npm install
  3. Iniciar el servidor en modo desarrollo:
  npm run dev
  4. Acceder a la API:
     Abre tu navegador o Postman en: http://localhost:3000
